# Simulated monthly Kuroshio offshore-distance time series

A simulated monthly time series representing the offshore distance of
the Kuroshio current path. The dataset is provided as a univariate `ts`
object and is intended for use as an example exogenous variable with
`sst_sim`.

## Usage

``` r
distance_sim
```

## Format

A univariate `ts` object with:

- frequency:

  12 (monthly data)

- start:

  January 1998

- end:

  February 2023

- distance:

  Simulated offshore distance of the Kuroshio current path

## Source

Simulated data generated for tempssm based on Baba et al. (2024). The
original study's supplementary code and test data are available at:
<https://github.com/logics-of-blue/sea-temperature-trend-jogashima>

## Details

The original source information used in Baba et al. (2024) was based on
the Japan Coast Guard's Ocean Current Forecasts and Reports, which
provide offshore-distance information for the Kuroshio current axis. The
original workflow used semi-monthly data with `frequency = 24`,
including preprocessing steps such as averaging within half-month
periods and linear interpolation for missing values. This simulated
dataset is represented as monthly data with `frequency = 12` for use
with the package examples.

This dataset is not the original observed Kuroshio-distance record. It
was generated by simulation based on the state-space model analysis of
sea temperature time series off Jogashima reported by Baba et al.
(2024). The name `distance_sim` is used to make the simulated nature of
the dataset explicit. Missing values, if any, are encoded as `NA`.

## References

Baba, S., Ishii, H., and Yoshiyama, T. (2024). Estimating sea
temperature trends using a linear Gaussian state-space model in
Jogashima, Kanagawa, Japan (in Japanese with an English abstract).

Baba, S. (2024). Supplementary code and test data for estimating sea
temperature trends using a linear Gaussian state-space model.
<https://github.com/logics-of-blue/sea-temperature-trend-jogashima>
